# Task Submission - Product Visuals & Art Direction (T2)

**Candidate:** Swyam Anand  
**Task:** T2 - Product Visuals & Art Direction  
**Product:** Smart 7.5-inch workspace display

## What I built

A cohesive set of five premium marketing visuals for a smart 7.5-inch always-on workspace display. The set covers Hero (personal schedule), Startup Command Center (business metrics), Meeting Room status, Restaurant specials board, and Focus Mode deep-work session. Each visual includes strong side-panel messaging and keeps the product recognizable, desirable and commercially relevant.

## How to view / use it

1. Browse the `screenshots/` folder for the five final visuals (01–05).
2. Read `work/exports/captions-and-art-direction.md` for the intent behind each image and the overall system.
3. Product reference photos used for accuracy are in `work/assets/`.
